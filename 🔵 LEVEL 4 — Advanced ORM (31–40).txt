3️⃣6️⃣ Mark books as is_popular if reviews > 100 (use Case).
❌ Incorrect---> review_above_hun = Review.objects.filter(book=OuterRef("pk")).annotate(review_count=Count("id"))
❌ Incorrect---> Book.objects.annotate(is_popular=Subquery(review_above_hun.values("review_count)[:1]))
                    
                    from django.db.models import Case, When, BooleanField, Count

✅ Correct Answer-->
                    Book.objects.annotate(
                        review_count=Count("review")
                    ).annotate(
                        is_popular=Case(
                            When(review_count__gt=100, then=True),
                            default=False,
                            output_field=BooleanField()
                        )
                    )

3️⃣8️⃣ Prevent overselling of books (locking required).
---> No Idea
✅ Correct Answer-->
                    from django.db import transaction

                    with transaction.atomic():
                        book = Book.objects.select_for_update().get(id=book_id)

                        if book.stock < quantity:
                            raise Exception("Out of stock")

                        book.stock -= quantity
                        book.save()
